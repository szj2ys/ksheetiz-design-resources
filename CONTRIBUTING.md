# Contributing to Design Resources

Thanks for your interest in contributing! Here's how to add or improve resources.

## Adding a Resource

1. **Fork** this repository
2. **Clone** your fork locally
3. **Create a branch**: `git checkout -b add-[resource-name]`
4. **Edit** `README.md` — add your resource to the correct section using the existing table format:
   ```
   | [Name](https://url.com) | Brief description of what it offers |
   ```
5. **Commit**: `git commit -m "Add [Resource Name] to [Section]"`
6. **Push** and open a **Pull Request**

## Guidelines

- ✅ Resources should be relevant to designers or frontend developers
- ✅ Clearly note if a resource is **premium** (paid) vs **free**
- ✅ Keep descriptions concise — one sentence max
- ❌ No affiliate links
- ❌ No duplicate entries (check before adding)

## Suggesting a New Category

Open an issue with the label `new-category` and describe the type of resources you'd like to see added.
